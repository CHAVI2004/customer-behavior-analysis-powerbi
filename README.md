# Customer Behavior & Purchase Analysis

## Project Overview

This project analyzes customer shopping behavior using SQL and Power BI.

The main goal is to understand customer purchasing patterns, product categories,
purchase amounts, customer ratings, subscriptions and shipping preferences.

## Business Problem

Raw customer transaction data can be difficult to understand and use for
business decisions. This project converts the raw data into meaningful
insights using SQL and an interactive Power BI dashboard.

## Tools Used

- SQL
- Power BI
- DAX
- Excel/CSV

## Key Analysis

- Customer purchase behavior
- Revenue by category and gender
- Average purchase amount
- Customer ratings
- Subscription analysis
- Shipping analysis
- Discount analysis
- Product performance
